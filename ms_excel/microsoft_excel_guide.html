1. Why Excel? & The Basics

Microsoft Excel is the industry leader, as far as general spreadsheet software goes, and it's not just for finance or math professionals! Literally every coworker I know uses Excel in some capacity! When I was a hall council member in college, we used Excel to plan our event budgets and schedules. Samantha Hunt, Director of the Testing Center, meticulously monitors the center's seat capacity for testing at all times using the most elaborate Excel workbook I've seen! My point is there are many different ways to use the software, because it's a versatile spreadsheet tool made for everyone! — Professor Haas

Excel documents are called workbooks, and each workbook contains multiple sheets (like pages in a notebook). Every cell is identified by its column letter and row number — for example, K7. The Name Box always shows you exactly which cell is currently active, so you never lose your place.

Excel Workbook Anatomy

Workbooks & Sheets

A workbook is the whole file; sheets are the individual tabs inside it (see Sheet Tabs at the bottom of the diagram — here, "Sheet1," "Budget," and "Assignment Tracker").

Name Box

Located just above the column headers, it displays the reference of whichever cell is currently selected (the Active Cell).

Fill Handle

The small black square at the bottom-right corner of a selected cell. Drag it to copy a value or formula down or across neighboring cells.

Rows & Columns

Column Headers (A, B, C...) run across the top; Row Headers (1, 2, 3...) run down the left. A cell reference always combines the two, e.g. B7.

2. Formatting

Formatting in Excel is split between two tabs: the Home tab handles the look of your data (fonts, alignment, colors), while the Page Layout tab handles how the whole sheet is arranged and printed.

Home Tab

Contains aesthetic formatting options: font, size, and both horizontal (left, right, center) and vertical alignment. Also where you'll find Bold (Ctrl+B) and number formatting like currency.

Page Layout Tab

Contains options for themes, margins, and page orientation — portrait (vertical) or landscape (horizontal). Scaling options here let you fit content to a specific page size.

Hands-On: Setting Up Your Workbook

  • Choose a theme: Page Layout tab → Themes → Select a theme
  • Bold text: Select cells → Home tab → Bold button (or Ctrl+B)
  • Change font size: Home tab → Font size dropdown
  • Center align: Home tab → Alignment section → Center
  • Left align: Home tab → Alignment section → Align Left

Hands-On: Working with Columns

  • Auto-fit column width: Double-click the border between column headers
  • Manual column width: Drag the border between column headers
  • Auto-fit via menu: Home tab → Format → AutoFit Column Width

Hands-On: Number Formatting

  • Apply currency format: Select cells → Home tab → Number section → Currency ($)
  • Or: Right-click → Format Cells → Currency
Format as Table: Home tab → Format as Table adds filters and alternating row colors in one click — a fast way to make raw data readable. See the Data Manipulation section for a visual example.

3. Formulas

Every formula starts with an equal sign (=) to signal to Excel that a calculation follows. Formulas are dynamic — they update automatically whenever the cells they reference change, which is what makes Excel more powerful than a static table.

Excel Formulas: Quick Reference

Basic Formulas

  • Simple calculation: =B2*(1+C2) (multiply cells)
  • SUM function: =SUM(D2:D4) (add a range of cells)
  • All formulas start with =

Absolute Cell References

  • Relative reference: B2 (changes when copied)
  • Absolute reference: $B$2 (stays locked when copied)
  • Mixed references: $B2 or B$2 (locks column or row only)
  • Shortcut: Press F4 to cycle through reference types (Windows)
  • Example: =B2*(1+$F$2) — locks the tax rate cell

TEXT Function

  • Purpose: Standardize date or number formats
  • Syntax: =TEXT(cell, "format_code")
  • Examples:
    • =TEXT(E2,"MM/DD/YYYY") → 01/15/2025
    • =TEXT(E2,"MMMM DD, YYYY") → January 15, 2025
    • =TEXT(A2,"$#,##0.00") → $1,234.56
Fill Handle: Once a formula works in one cell, drag the Fill Handle (the black crosshair at the bottom-right corner) down or across to copy it — relative references adjust automatically, absolute references ($) stay put.

4. Data Manipulation

The Data tab offers options to sort, filter, and validate data, while several of these tools — conditional formatting and Format as Table — live on the Home tab since they're about presentation as much as data management.

Excel Data Tools: At a Glance

Conditional Formatting

Highlights cells that meet specific criteria — for example, coloring performance percentages green, yellow, or red. Found under Home tab → Conditional Formatting.

Format as Table

Provides consistent formatting with alternating row colors, plus built-in filter arrows, in a single click. Found under Home tab → Format as Table.

Filtering

Shows only the rows that meet criteria you choose — check or uncheck categories from a dropdown. Found under Data tab → Filter.

Sorting

Organizes data alphabetically or numerically, ascending or descending. Found under Data tab → Sort.

Data Validation (Data tab) creates dropdown lists so data entry stays consistent, and Pivot Tables summarize large datasets for analysis — both are worth exploring once you're comfortable with sorting and filtering.

5. Charts

Charts turn rows of numbers into something a reader can understand at a glance. The Insert tab is where every chart begins — select your data first, then choose a chart type.

Excel Chart Formatting Guide

  • Insert tab allows creation of charts and other visual elements
  • Excel recommends appropriate chart types based on the data you've selected
  • Charts update automatically when the underlying data changes
  • Chart elements (titles, axes, legends) can be edited for clarity
Editing chart elements: Right-click any chart element to format it, or select the chart and use the Chart Tools tabs that appear in the Ribbon.

6. Quick Reference

A condensed cheat sheet of keyboard shortcuts and printing steps for when you just need the answer fast.

Keyboard Shortcuts

Save: Ctrl+S (Mac: Cmd+S)
Undo: Ctrl+Z (Mac: Cmd+Z)
Copy: Ctrl+C (Mac: Cmd+C)
Paste: Ctrl+V (Mac: Cmd+V)
Bold: Ctrl+B (Mac: Cmd+B)
Absolute Ref: F4 (Windows)

Printing & Export

  • Print setup: File → Print
  • Fit to one page: Print settings → "Fit Sheet on One Page"
  • Adjust margins: Print settings → Margins dropdown
  • Print to PDF (Mac): Print dialog → PDF (bottom left) → Save as PDF
  • Print to PDF (Windows): Print dialog → Printer → Microsoft Print to PDF
  • Preview page breaks: View tab → Page Layout view
